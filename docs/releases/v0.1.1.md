# ClearDesk v0.1.1

19 November 2026 · First public release of an independent local reference application.

ClearDesk is a permission-aware internal knowledge assistant. A Mastra agent can search and read company documents through two scoped tools, while application code decides who may read what, which citations are valid and which saved answers remain visible after access changes.

## What changed since v0.1.0

See [CHANGELOG.md](../../CHANGELOG.md). In short: normal chat no longer shares the bounded evaluation allowance, the chat size limit covers chunked uploads, missing CSRF tokens return 403, two small interface defects are fixed, browser runs no longer overwrite hash-bound evidence images, `verify` and `assess:http` work on a fresh clone, and the dependency advisory history is reconciled.

## Limits

This is a local reference with synthetic data, not a production deployment, a security certification or a claim of universal prompt-injection resistance. A valid citation proves provenance, not factual correctness. See [LIMITATIONS.md](../LIMITATIONS.md).
